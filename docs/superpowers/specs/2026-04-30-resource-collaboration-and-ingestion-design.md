# 资源协作与开放资源采集设计

## 背景

当前资源库主要依赖管理员手动上传，扩展速度慢，维护成本高，也无法覆盖更多开放学习资源。仅靠人工上传，资源库很难持续增长，推荐能力也会受限。

需要新增一套资源协作与开放资源采集机制，让平台同时支持：

- 管理员维护全站资源与审核规则
- 普通用户申请成为资源库协作者
- 协作者管理自己提交和采集的资源
- 平台采集开放资源，包括文档类与视频类

## 目标

- 降低资源库对纯手工上传的依赖
- 允许合格用户参与资源建设，但不放开全站后台权限
- 支持文档类内容型采集与视频类索引型采集
- 保持资源质量、来源可控、审核链路清楚
- 为后续学习方向推荐、资源自动匹配打基础

## 非目标

- 第一版不做全网无限制抓取
- 第一版不做视频字幕转写或音频转文本
- 第一版不做公开社区投稿系统
- 第一版不做自动无审核入库
- 第一版不把协作者升级为真正平台管理员

## 核心结论

### 角色设计

系统新增独立资源权限，不直接复用 `ADMIN`。

角色划分：

- 普通用户：只能提交资源协作者申请
- 资源库协作者：只能进入自己的资源管理页面，只管理自己提交与采集的资源
- 平台管理员：审核申请、审核资源、管理来源、管理全站资源

### 权限边界

资源库协作者可以：

- 进入“我的资源管理”
- 创建资源采集任务
- 提交资源链接
- 查看和编辑自己名下的候选资源
- 提交入库申请
- 查看审核状态
- 重新提交被驳回资源

资源库协作者不能：

- 审核别人资源
- 修改别人资源
- 查看全站资源管理数据
- 管理来源白名单
- 进入平台总后台其他管理模块

## 资源类型

### 内容型采集

适用来源：

- 官方文档
- GitHub Docs / README
- 教程站
- 技术博客
- 开放课程说明页

入库内容：

- 标题
- 摘要
- 来源链接
- 标签
- 所属方向
- 内容正文或结构化内容
- 来源站点

### 索引型采集

适用来源：

- B 站
- 其他公开视频平台

入库内容：

- 视频标题
- 简介
- UP 主 / 作者
- 封面
- 时长
- 标签
- 跳转链接
- 所属方向
- 适合阶段

第一版不抓视频正文，不抓字幕，不做音频转写。

## 页面结构

### 1. 资源协作者申请页

对象：普通用户

作用：

- 提交成为资源库协作者的申请
- 填写申请理由
- 填写擅长方向或资源来源说明
- 查看申请状态

状态：

- 待审核
- 已通过
- 已拒绝

### 2. 我的资源管理

对象：资源库协作者

作用：

- 创建资源采集任务
- 管理自己提交的候选资源
- 查看资源状态
- 编辑标题、摘要、标签、分类
- 提交资源入库申请

资源状态建议：

- 草稿
- 待采集
- 采集中
- 待整理
- 待审核
- 已通过
- 已拒绝

### 3. 资源审核后台

对象：平台管理员

作用：

- 审核协作者申请
- 审核候选资源
- 查看资源来源
- 管理来源白名单
- 处理驳回原因

## 流程设计

### 用户申请流程

1. 普通用户提交成为资源库协作者的申请
2. 管理员审核申请
3. 审核通过后，用户获得资源协作者权限
4. 前端出现“我的资源管理”入口

### 资源采集流程

1. 协作者进入“我的资源管理”
2. 手动提交资源链接或发起采集
3. 系统根据来源类型执行内容型或索引型采集
4. 系统生成候选资源
5. 协作者补充标题、标签、方向、说明
6. 协作者提交审核
7. 管理员决定通过或驳回
8. 审核通过后进入平台正式资源库

### 管理员审核流程

管理员对资源可执行：

- 通过
- 驳回
- 要求补充信息
- 拉黑来源

## 来源白名单机制

第一版不允许任意来源直接采集，必须走来源控制。

来源处理规则：

- 平台管理员维护来源白名单
- 白名单来源允许采集
- 非白名单来源可提交候选，但必须经过管理员判断
- 被判定风险过高的来源可加入黑名单

来源分类建议：

- 官方文档站
- GitHub 仓库文档
- 开放课程页
- 博客 / 教程站
- 视频平台

## 数据对象建议

第一版至少包含这些业务对象：

- 协作者申请
- 协作者权限
- 资源来源配置
- 资源采集任务
- 候选资源
- 正式资源
- 审核记录

## 审核与质量规则

平台必须保留最终入库权。

质量控制建议：

- 自动做基础去重
- 自动识别来源类型
- 自动生成摘要和标签建议
- 管理员最终确认是否进入正式资源库

驳回时应记录：

- 驳回原因
- 是否允许修改后重新提交

## 与现有资源库的关系

这套能力不是替换现有资源库，而是扩展资源进入方式。

保留现有能力：

- 管理员手动上传
- 资源预览
- 资源推荐

新增能力：

- 协作者提交
- 开放资源采集
- 候选资源审核

## 验收标准

- 普通用户可以提交资源协作者申请
- 管理员可以审核申请
- 审核通过的用户可进入“我的资源管理”
- 协作者只能看到和管理自己的资源
- 平台管理员可以查看和审核全部候选资源
- 系统能区分内容型采集和索引型采集
- 视频类资源第一版只做索引采集
- 审核通过后资源进入正式资源库
- 未通过的资源不会直接进入正式资源库
- 来源白名单和黑名单机制有效
