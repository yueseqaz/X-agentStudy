# 前端页面规格

## 技术基线

- Vue 3 + Vite + TypeScript。
- Vue Router 管理页面。
- Pinia 管理用户、当前方向、当前计划、任务状态。
- Axios 封装 API client。
- UI 组件库默认 Element Plus。

## 路由建议

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 工作台 | 方向概览、最近计划、今日复习 |
| `/login` | 登录页 | 登录、注册入口 |
| `/directions` | 学习方向页 | 方向列表和创建入口 |
| `/directions/:directionId/profile` | 画像 Agent 对话页 | 采集学习画像 |
| `/profiles/:profileId` | 画像结果页 | 确认、补充、重生成 |
| `/plans/:planId` | 学习计划页 | 阶段、任务、进度 |
| `/plans/:planId/knowledge` | 知识库页 | 上传、列表、摘要、状态 |
| `/plans/:planId/qa` | 问答页 | 聊天、引用、推荐追问 |
| `/plans/:planId/quiz` | 测验页 | 生成题目、答题、解析 |
| `/plans/:planId/questions` | 题库页 | 筛选、错题、重做 |
| `/plans/:planId/review` | 复习页 | 今日复习、薄弱点 |
| `/plans/:planId/report` | 学习报告页 | 周报、进度、建议 |
| `/notifications` | 通知中心 | 复习提醒、任务提醒 |
| `/billing` | 订阅与额度 | 套餐、用量、升级入口 |
| `/admin` | 管理后台 | 指标、任务、用户、用量 |

## 状态管理

### userStore

- 当前用户。
- 登录状态。
- 权限上下文。
- 订阅状态和额度。

### learningStore

- 当前学习方向。
- 当前学习计划。
- 方向列表。
- 计划阶段和任务状态。

### taskStore

- 文档解析任务。
- Agent 生成任务。
- 轮询状态。
- 错误信息。

## 页面细节

### 学习方向页

- 左上方为创建方向按钮。
- 方向卡片展示名称、分类、说明、最近活跃时间。
- 方向卡片提供进入、编辑、删除操作。
- 空状态应引导创建第一个方向。

### 画像 Agent 对话页

- 对话区展示 Agent 提问和用户回答。
- 输入区支持跳过、补充、提交。
- 顶部展示当前方向名称和采集进度。
- 生成画像时显示加载状态。

### 学习计划页

- 顶部展示计划目标、状态、当前阶段。
- 主体为阶段时间线和任务列表。
- 任务支持完成状态切换。
- 提供重新生成或微调入口。

### 知识库页

- 上传区域支持拖拽和按钮上传。
- 文档表格展示名称、类型、解析状态、摘要、上传时间。
- 解析中状态需要轮询任务。
- 解析失败显示失败原因和重试按钮。

### 问答页

- 左侧或主区域为聊天消息。
- 回答中展示引用文档、页码/章节、相关知识点。
- 输入区提供更简单、举例说明、继续展开等快捷追问。
- 当前计划提示必须明显，避免用户误以为是全局问答。

### 测验页

- 生成设置区包含难度、题量、题型、范围。
- 生成过程显示任务状态。
- 题目区域支持选择题和简答题。
- 提交后展示正确性、标准答案和解析。

### 题库页

- 支持按知识点、难度、题型、是否错题筛选。
- 历史作答记录可展开查看。
- 重做不覆盖历史记录，新增作答记录。

### 复习页

- 今日复习按优先级排序。
- 每条复习建议展示知识点、原因、来源计划、完成状态。
- 当前计划页展示单计划复习，工作台聚合多计划待复习内容。

### 学习报告页

- 展示完成任务、未完成任务、活跃度、薄弱点、下一步动作。
- 文案应具体，避免泛泛鼓励。

### 订阅与额度页

- 展示当前套餐、剩余额度、模型调用用量、知识库容量。
- 免费版限制计划数量、知识库容量、每日问答和测验生成次数。
- Pro 版展示升级入口，支付未接入时可先进入等待名单或人工开通。

### 管理后台

- 展示注册、活跃、画像完成、计划生成、上传资料、问答、测验等指标。
- 展示 Agent 任务状态、失败原因、模型调用耗时和 token 用量。
- 支持查看用户列表和用量概览。

## 交互状态

| 状态 | 要求 |
| --- | --- |
| Loading | AI 生成、文档解析、上传必须有可见状态 |
| Empty | 无方向、无文档、无题目、无复习时给出下一步操作 |
| Error | 错误信息可解释，提供重试或返回 |
| Disabled | 无知识库时测验和问答可降级，但要提示 |
