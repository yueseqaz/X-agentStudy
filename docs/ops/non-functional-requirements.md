# 非功能需求

## 性能

- 普通页面接口建议 P95 小于 500ms。
- AI 生成类接口必须有任务状态或流式反馈。
- 文档上传后立即返回文档记录和任务 ID。
- 文档解析、摘要、向量化、出题生成不应阻塞普通请求线程。

## 可用性

- 首次流程应尽量短：方向创建后直接进入画像 Agent。
- 所有长任务必须展示明确进度或状态。
- 错误状态需要提供原因和下一步动作。
- 空状态应引导用户继续完成学习闭环。

## 安全与隐私

- 不同用户数据隔离。
- 不同学习计划知识库隔离。
- 上传资料仅用于当前用户对应计划。
- 删除资料时同步清理向量索引。
- 生产环境必须限制文件大小和文件类型。
- 完整版本需具备额度、限流、审计日志和账号注销能力。

## 可靠性

- Agent 任务和文档解析任务需要记录输入、输出、状态和错误。
- 异步任务支持重试。
- 模型调用失败时要返回可解释错误。
- 向量库不可用时可降级，但不能返回错误引用。

## 可观测性

建议记录：

- 请求日志和 `requestId`。
- Agent 调用耗时、模型、token 用量、错误。
- 文档解析耗时和失败原因。
- RAG 召回数量、相似度、引用文档。
- 关键业务埋点：创建方向、完成画像、生成计划、上传资料、问答、生成测验、提交答案、完成复习。

## 埋点指标

| 类型 | 指标 |
| --- | --- |
| 转化 | 注册用户数、创建方向率、完成画像率、生成计划率、首次上传资料率 |
| 活跃 | DAU、WAU、问答次数、测验次数、资料上传数 |
| 留存 | 次日留存、7 日留存、30 日留存 |
| 学习效果 | 计划完成率、题目完成率、错题重做率、复习完成率 |
