# 完整产品范围定义

## 产品定位

面向技能学习型个人用户的 AI 学习 SaaS 平台，通过多 Agent 协作提供从学习诊断、路径规划、资料沉淀、答疑教学、测验练习到复习反馈的学习闭环。

## 产品目标

- 建设一个完整的多 Agent 协作技能学习 SaaS 平台。
- 支持个人学习用户从目标诊断、计划生成、资料管理、AI 答疑、测验、复习、报告到付费订阅的完整闭环。
- 支持后续扩展到移动端、团队版、企业学习和导师增强服务。
- 形成可商业化运营的账户、权限、额度、订阅、埋点和数据安全能力。

## 7.1 无知识库冷启动机制

为提升新用户首次体验与 AI 能力感知，系统不得将知识库作为核心 AI 能力的前置条件。知识库是增强层，不是启用条件。

### 设计原则

- 用户即使未上传任何资料，也能立即使用核心 AI 能力。
- 产品必须同时支持“无知识库模式”和“知识库增强模式”。
- 当计划内没有可用资料、资料解析失败、检索为空或向量库不可用时，系统应自动进入无知识库模式。
- 当计划内存在解析成功的资料并能检索到相关片段时，系统应进入知识库增强模式。
- UI 必须清楚标识当前回答或题目是否引用了计划资料，避免用户误以为通用回答来自个人资料。

### 无知识库模式下可用能力

- 学习画像生成。
- 学习路径生成。
- 通用知识讲解。
- 通用练习题生成。
- 学习建议与阶段总结。
- 模拟提问、面试、互动式讲解。

### 知识库增强模式下新增能力

- 基于资料的精准问答。
- 基于资料的题目生成。
- 文档摘要与重点提取。
- 资料引用与出处展示。
- 基于文档内容的复习推荐。
- 基于资料内容的学习计划动态优化。

### 产品价值

通过无知识库冷启动机制，用户首次进入产品时即可感知 AI 的核心价值，降低上传资料前的使用门槛，提升首次转化率；后续上传资料后，系统再升级为更个性化、更贴合实际学习内容的智能学习平台。

## 仍不建议首版实现

- 直播课和完整视频课系统。
- 开放式学习社区。
- 外部课程平台深度集成。
- 复杂游戏化成长体系。
- 原生移动 App。

这些能力可以在架构上预留，但不进入首个完整 Web 版本的主开发范围。

## 完整版本验收标准

- 用户可以注册登录并管理个人资料。
- 用户可以在首次访问中完成学习方向创建、画像采集和计划生成。
- 用户未上传资料时，也可以进行通用问答、生成通用练习题和获得学习建议。
- 用户可以在某个计划下上传资料，并看到解析状态和摘要。
- 用户可以围绕当前计划发起问答，回答能展示计划内引用来源。
- 用户可以生成测验，提交答案，题目和作答记录能归档到该计划下。
- 用户可以查看题库、错题、复习建议和学习报告。
- 用户可以在工作台看到多计划学习概览和今日待办。
- 多个学习计划的数据不会在知识库、问答、题库、复习中混杂。
- 系统具备账号、权限、额度、订阅预留、埋点和管理后台基础能力。
- 管理员可以查看关键运营指标、模型调用情况和异常任务。
