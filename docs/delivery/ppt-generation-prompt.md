## 二、项目背景信息（请严格基于以下内容）

项目名称：X-AgentStudy  
定位：多 Agent 协作技能学习 SaaS 平台  
核心理念：一个学习计划 = 一个完整学习空间（计划级隔离）

当前已实现模块：
- 账号安全：注册登录、Refresh Token、密码重置、邮箱验证、账号封禁、头像
- 学习方向：创建/编辑/删除
- 画像 Agent：对话生成学习画像
- 规划 Agent：生成章节化计划（单元 + 知识点）
- 计划工作台（Tab）：计划详情、知识库、AI 问答、测验题库、总结图、复习清单、学习报告
- 知识库：文档上传、解析状态、摘要、章节结构、知识点树、在线文档生成
- AI 问答：支持无知识库冷启动 + 知识库增强模式
- 测验题库：客观题自动判分；主观题/代码题/案例题/面试题 AI 评估；错题重做
- 复习清单：按计划沉淀弱项
- 学习报告：掌握度、正确率、趋势
- 总结图：文档提炼 -> 前端模板渲染 -> 导出图片 -> 计划内归档/预览/下载
- 每日打卡：全局日历、连续打卡、当日学习记录
- 订阅体系：Free/Plus/Pro、钱包充值、模拟购买、额度拦截
- 管理后台：用户管理、任务管理、额度管理、钱包充值、审计日志、模型配置

技术栈：
- 前端：Vue 3 + TypeScript + Vite + Vue Router + Pinia + Element Plus + Axios
- 后端：Java 17 + Spring Boot + Spring MVC + Spring Data JPA + Spring Security
- 数据：MySQL + Flyway + Redis
- AI：DeepSeek API（管理员模型配置生效）
- 检索：Remote-first embedding（失败回退本地 embedding）
- 文档处理：PDFBox + Apache POI

部署方式：
- Docker Compose 部署
- 非 Docker 本地部署（Java + Node + MySQL + Redis）

## 三、输出格式要求

5. **结尾页文案（2 个版本）**

6. **30 秒电梯陈述（1 段）**

7. **答辩高频问题与回答（至少 10 组）**
