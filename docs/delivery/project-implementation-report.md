# X-AgentStudy 项目实现报告（截至 2026-05-07）

## 1. 项目概览

X-AgentStudy 已从“方向创建 + 画像 + 计划”的早期版本，扩展为一个可完整跑通的学习闭环平台。  
当前系统以“计划级隔离”为主线，把资料、问答、题库、复习、报告、总结图都收纳到同一个学习计划内。

---

## 2. 已实现功能清单

### 2.1 账号与安全

- 注册、登录、刷新 token、退出登录
- 密码重置 token 申请与确认
- 邮箱验证 token 申请与确认
- 登录失败计数与临时锁定
- 账号封禁（含封禁截止时间）
- 最近登录时间、安全状态查询
- 头像上传

对应后端模块：
- `auth/*`
- `common/security/*`
- `user/*`

### 2.4 计划级知识库与在线文档

## 3. 技术栈与模块分工

| 层 | 技术栈 | 作用 |
|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Vue Router + Pinia + Element Plus + Axios | SaaS 页面、计划工作台、交互状态、鉴权跳转 |
| 后端 | Java 17 + Spring Boot + Spring MVC + Spring Data JPA + Spring Security | 业务 API、权限、任务编排、数据一致性 |
| 数据库 | MySQL + Flyway | 主数据存储、结构迁移版本化 |
| 缓存/状态 | Redis | 会话相关与扩展缓存能力 |
| AI 调用 | DeepSeek Chat API（可配置） | 画像、规划、讲义、问答、出题、批改、总结提炼 |
| 检索 | RemoteFirst Embedding + 本地 fallback embedding | 向量化检索（远端优先，失败回退本地） |
| 文档处理 | PDFBox、Apache POI | 文档解析（PDF/PPT/DOCX 等） |

## 8. A3 赛题对照补充

### 8.1 画像要求

赛题要求通过自然语言对话构建不少于 6 个维度的动态学生画像。当前系统已支持画像 Agent 问答，并在画像结果页显式展示：

- 学习目标
- 知识基础
- 学习节奏
- 认知风格
- 易错点
- 资源偏好

动态画像服务还会结合学习报告、错题、资料行为继续更新画像可信度和推荐依据。

### 8.2 至少 5 类资源生成

当前项目可展示的资源类型包括：

| 资源类型 | 项目能力 |
|---|---|
| 专业课程讲解文档 | 在线学习文档生成，Markdown 渲染 |
| 知识点思维导图 | 计划知识点生成可交互导图 |
| 不同类型练习题目 | 选择、填空、主观、代码、案例、面试题 |
| 拓展阅读材料 | 资源库与课程资源采集、推荐 |
| 多模态教学视频/动画 | Remotion 知识视频生成 |
| 代码类实操案例 | 代码题与 AI 批改反馈 |
