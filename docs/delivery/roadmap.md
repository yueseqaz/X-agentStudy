# 开发路线图

说明：产品目标调整为完整 SaaS 版本，不再以 MVP 验证为终点。工程交付仍建议分阶段推进，原因是完整能力涉及账号、权限、知识库、Agent、异步任务、订阅、管理后台和数据安全，分阶段可以降低集成风险。

## Phase 0：工程初始化

目标：建立可运行、可扩展的前后端项目骨架。

- 初始化 Spring Boot 项目。
- 初始化 Vue 3 + Vite + TypeScript 项目。
- 配置 MySQL、Redis、向量库、文件存储。
- 定义统一响应、异常、日志、鉴权和权限上下文。
- 建立数据库迁移机制。
- 建立 Prompt 模板目录和模型网关接口。

## Phase 1：账号、方向、画像、计划

目标：打通用户身份和学习计划主链路。

- 注册登录、JWT、当前用户。
- 学习方向 CRUD、搜索、归档。
- 画像 Agent 对话、画像生成、画像版本。
- 规划 Agent 生成学习计划。
- 学习计划阶段、任务、进度、微调。

验收：登录用户能完成方向创建、画像生成、计划生成和计划调整。

## Phase 2：知识库、文档流水线、RAG 问答

目标：打通计划级资料沉淀和个性化答疑。

- 文档上传、列表、删除、重试。
- PDF、PPT/PPTX、Markdown、TXT、DOCX、网页链接解析。
- 异步任务状态和失败重试。
- 文档摘要、切片、向量化、来源映射。
- 计划级 RAG 检索。
- 计划内问答、引用展示、追问、问答历史。

验收：用户能上传多类型资料，并基于当前计划资料进行带引用的问答。

## Phase 3：测验、题库、错题、复习

目标：形成练习、反馈和复习闭环。

- 测验配置和异步题目生成。
- 题目归档到计划题库。
- 作答、解析、多次作答记录。
- 错题筛选和知识点统计。
- 复习建议、遗忘风险、完成记录。

验收：用户能完成题目生成、答题、查看错题，并收到基于薄弱点的复习建议。

## Phase 4：学习报告、通知、工作台

目标：增强持续学习管理能力。

- 工作台多计划概览。
- 今日待办、最近学习、待复习内容。
- 日报、周报、阶段报告。
- 站内通知和复习提醒。
- 学习数据埋点。

验收：用户能在工作台掌握多计划状态，并收到可执行的学习反馈和提醒。

## Phase 5：订阅额度与管理后台

目标：具备商业化运营和后台管理基础。

- 免费版、Pro 套餐配置。
- 计划数量、知识库容量、问答次数、测验生成次数限制。
- 用量统计和额度扣减。
- 支付接口预留或人工开通入口。
- 管理后台：用户、指标、Agent 任务、用量、异常任务。
- 审计日志。

验收：系统能限制和统计用量，管理员能查看核心运营与 AI 任务数据。

## Phase 6：团队、导师与多端预留

目标：为企业版和导师增强服务扩展。

- 组织、成员、角色。
- 团队学习计划和组织管理员。
- 导师角色和学习点评入口。
- 移动 H5 适配。
- 原生 App API 边界预留。

验收：系统具备从个人 SaaS 扩展到团队/企业场景的基础模型和接口。

## 里程碑建议

| 周期 | 目标 |
| --- | --- |
| Week 1-2 | 工程初始化、账号权限、基础表、方向模块 |
| Week 3-4 | 画像 Agent、计划生成、计划页、前端主布局 |
| Week 5-6 | 文档上传、异步解析、知识库、向量化 |
| Week 7-8 | RAG 问答、引用展示、问答历史 |
| Week 9-10 | 测验生成、题库、作答、错题 |
| Week 11 | 复习、报告、通知、工作台 |
| Week 12 | 订阅额度、管理后台、联调验收 |
