# X-AgentStudy

X-AgentStudy 是一个面向自主学习场景的 AI 学习平台。项目围绕学习目标、学习计划、资料理解、智能问答、测验练习、复习报告和社区讨论，帮助用户把一个学习方向拆成可执行、可追踪、可复盘的学习过程。

平台支持用户创建学习方向，生成个人学习画像和学习计划，并在学习过程中使用 AI 辅助问答、资料总结、题目生成、答案批改和阶段复盘。用户也可以上传学习资料，让系统围绕资料内容提供更贴近当前学习任务的回答和练习。

## 核心能力

- 学习画像：根据学习目标、基础水平、时间安排和偏好生成个性化分析。
- 学习计划：自动生成章节、知识点、任务和阶段目标。
- AI 问答：结合学习计划和资料内容回答问题。
- 资料处理：支持上传文档，提取内容并用于问答、讲义和题目生成。
- 题库测验：生成练习题，记录作答结果，并提供 AI 反馈。
- 学习报告：汇总学习进度、正确率、薄弱点和后续建议。
- 问答社区：支持用户发布问题、回答问题，也可以邀请 AI 参与回答。
- 管理后台：提供用户、资源、额度和模型配置管理。

## 项目组成

- 后端：基于 Spring Boot，负责账号权限、学习计划、AI 调用、资料处理、题库、社区和管理后台。
- 前端：基于 Vue 3，提供学习端、社区端和管理端页面。
- AI 能力：通过 Spring AI 接入 OpenAI-compatible 模型，当前可用于 DeepSeek 等兼容服务。

## 适用场景

X-AgentStudy 适合作为 AI 教育产品原型、课程设计、软件设计大赛作品或个人学习助手项目。它的重点不是单次问答，而是把学习目标转化为持续的学习闭环。
