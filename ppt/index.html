ProblemAI Learning Platform
Learning Gap
Problem

学习不是缺内容，而是缺连续的路径。

01
目标容易模糊
用户知道想学某个方向，但不知道该先补基础、再做什么练习。
02
资源分散难筛
视频、文档、图片、音频各自存放，缺少统一标签和推荐规则。
03
过程缺少反馈
计划、笔记、练习、复盘彼此断开，很难形成稳定闭环。

ConceptAI Learning Platform
Closed Loop
Product Thesis

用平台把“方向、计划、资源、练习、复盘”串成一个学习闭环。

AI 负责生成和辅助判断，系统负责保存过程、推荐资源、呈现状态，管理员负责维护内容质量。

SystemAI Learning Platform
Architecture
Architecture

系统由前端、后端、数据库和模型服务组成。

Vue 前端
负责页面、筛选、预览、引导和学习工作流展示。
Spring Boot 后端

MySQL

Model Gateway
对接 DeepSeek 等模型，统一生成入口。
文件存储
保存上传资源，并通过访问接口进行预览。
